# Visual Quality Review & Self-Assessment Rubric (docs/UX-REVIEW.md)

## Evaluation Dimensions (Score 0 to 5)
1. **Visual Hierarchy**: Immediate clarity of primary vs secondary workflows within 3 seconds.
2. **Alignment & Grid Rhythm**: Pixel-perfect adherence to 4px/8px grid system with no arbitrary margins.
3. **Information Density**: Efficient desktop screen usage without oversized padding or cramped text.
4. **Readability & Typography**: Clear Segoe UI weights, high contrast, perfect Greek diacritic rendering.
5. **Interaction Clarity**: Obvious clickable targets, clear disabled states, hover feedback.
6. **State Representation**: Distinct active navigation, empty states, loading indicators, and field validation.
7. **Empty State Quality**: Purposeful empty placeholders with vector icon, explanation, and action button.
8. **Keyboard Usability**: Tab order, shortcuts, arrow navigation, enter/escape behavior.
9. **Legacy Windows Consistency**: Flawless GDI/WPF rendering on Windows 7 SP1 up to Windows 11 without artifacts.
10. **Product Identity**: Disciplined Hellenic administrative workstation aesthetic (zero AI templates, zero emoji).
