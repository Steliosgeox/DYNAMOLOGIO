# Assumptions Register (docs/ASSUMPTIONS.md)

| ID | Description | Reason | Impact | Status | Evidence | Resolution |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| **ASM-001** | Date semantics use explicit half-open interval `[StartAt, ReturnAtExclusive)`. If operator inputs "Από 16/08" and "Επιστροφή 21/08", the person is absent on 16, 17, 18, 19, 20 and present on 21/08 at 00:00. | Standard Greek administrative practice where return date marks resumption of active service. | Absence math and presence calculation. | **CONFIRMED** | Master Build Prompt Section 16 & Section 41. | Implemented in `StatusIntervalMath.cs`. |
| **ASM-002** | Base personnel hierarchy consists of Στελέχη (Officers/NCOs) and Οπλίτες (Enlisted Soldiers/Conscripts). | Core organizational division in Hellenic Armed Forces units. | Dashboard grouping, strength breakdown buckets, and reporting tabs. | **CONFIRMED** | Standard DYNAMOLOGIO reporting structure. | Configurable enum and lookup table `PersonnelCategory`. |
| **ASM-003** | Basic absence types include: Κανονική Άδεια (Regular Leave), Αναρρωτική Άδεια (Sick Leave), Τιμητική Άδεια (Honorary Leave), Φύλλο Πορείας (Movement Order/Transfer), Ειδική Άδεια (Special Leave), Νοσηλεία (Hospitalization), Φυλακή/Κράτηση (Detention/Disciplinary), Αποσπασμένος (Detached/Temporary Duty). | Standard absence classifications in military administrative offices. | Status type catalog and official report grouping. | **CONFIRMED** | Master Build Prompt & standard military templates. | Seeded in default database migration and fully configurable. |
| **ASM-004** | Standard duty/service assignments (Υπηρεσίες) include: Αξιωματικός Υπηρεσίας (Duty Officer), Βοηθός Αξ/κου Υπηρεσίας (Assistant Duty Officer), Επόπτης Ασφαλείας (Security Supervisor), Αρχιφύλακας (Head Guard), Σκοπός (Sentry), Θαλαμοφύλακας (Barracks Sentry), Περίπολος (Patrol), Εστιάτορας (Mess Guard), Μαγειρείο (Kitchen Duty). | Typical operational roster duties. | Service assignment roster and day/night duty reporting. | **CONFIRMED** | Standard operational roster templates. | Seeded in default configuration with full user-editing capability. |
| **ASM-005** | Service assignments (Υπηρεσίες) do NOT automatically mark a person absent unless specifically configured by the operator (e.g. 24-hour off-base patrol). | Most services are performed inside unit grounds while person remains in present strength. | Strength invariant calculations. | **CONFIRMED** | Master Build Prompt Section 22. | `ServiceType.AffectsPresence` configurable flag. |
| **ASM-006** | Single-workstation standalone database (`%PROGRAMDATA%\Dynamologio\Data\dynamologio.db`). Multi-user concurrent network share access is disabled in V1 to prevent file lock corruption. | LiteDB single-file embedded architecture requirements. | Data integrity on legacy PCs. | **CONFIRMED** | Master Build Prompt Section 11 & Section 31. | Enforced in `LiteDbContext`. |
| **ASM-007** | Ranks are sorted by military precedence (Αντιστράτηγος down to Στρατιώτης) using a configurable `SortOrder` integer. | Official reports require sorting by descending seniority within each unit/category. | Report row ordering and grid sorting. | **CONFIRMED** | Standard Hellenic military precedence list. | Seeded with standard Army ranks, editable by Admin. |
